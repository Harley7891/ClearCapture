# Contributing

Set up using README.md, work on a focused branch, and preserve the sandboxed renderer/native-host separation. Add a regression test for behavior changes, run the unit/syntax/localization suite and relevant native integration tests. Capture/device and lifecycle fixes need real saved-media evidence rather than a screenshot of controls.

Keep all five dictionaries aligned. Never add hidden telemetry, external uploads, unrestricted preload APIs or remote executable content. New codecs, devices and dependencies must document platform support and licenses. Reports should state Windows version, app version, reproduction steps and sanitized logs; avoid sharing private recordings.

Application contributions are distributed under GPL-3.0-only. Propose significant architecture or public API changes before implementing them. Use [GitHub Issues](https://github.com/Harley7891/ClearCapture/issues) for reproducible, sanitized bug reports and [pull requests](https://github.com/Harley7891/ClearCapture/pulls) for contributions.
